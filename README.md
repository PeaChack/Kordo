# Kordo

**Kordo пускает через ваш VPN только те программы, которые вы выбрали.** Браузер — через сервер в Нидерландах, игры и банк — напрямую, Telegram — через домашний WireGuard. Остальной компьютер работает как обычно.

Kordo — программа для Windows 10 и 11 для тех, у кого есть свой VPN- или прокси-сервер: VLESS (в том числе Reality), Shadowsocks или WireGuard. Ссылку на сервер вы вставляете в окно Kordo — и всё, никаких конфигов руками.

Бесплатно, с открытым исходным кодом (GPL-3.0).

## Что умеет

- **Выбор приложений.** Добавьте программу из списка запущенных или установленных, выберите `.exe` или ярлык, или просто перетащите файл в окно. Для каждой — свой маршрут: через какой-то из ваших серверов, напрямую или «заблокировать».
- **Два режима.** «Через VPN только выбранные» или наоборот «Всё через VPN, кроме выбранных».
- **Программы, которые запускает приложение,** идут тем же путём, что и оно само (или напрямую, или Kordo спросит — как настроите).
- **Kill switch.** Если VPN упал, Kordo может заблокировать интернет VPN-приложениям или всему компьютеру, чтобы ничего не ушло мимо туннеля.
- **DNS без утечек.** Запросы имён шифруются; провайдер их не видит.
- **Значок в трее.** Цветной — VPN подключён, серый — нет. Окно можно закрыть, Kordo продолжит работать.
- **Экран «Активность».** Видно, какое приложение куда сейчас подключено и через какой сервер.
- **Сам обновляется.** Когда выходит новая версия, Kordo предложит её поставить.

## Установка

1. Скачайте `Kordo-Setup-<версия>.exe` со страницы [Releases](https://github.com/PeaChack/Kordo/releases).
2. Запустите и согласитесь на права администратора: они нужны, чтобы установить службу Kordo, которая управляет туннелем.
3. В конце оставьте галочку «Запустить Kordo».

> **Windows или браузер ругаются на файл?** Kordo пока не подписан сертификатом разработчика, поэтому для Windows это «неизвестный издатель».
> - SmartScreen («Система Windows защитила ваш компьютер»): нажмите «Подробнее» → «Выполнить в любом случае».
> - Firefox («Этот файл содержит вирус…»): откройте список загрузок (`Ctrl+Shift+Y` или стрелка на панели), нажмите правой кнопкой на файл → «Разрешить загрузку».
>
> Убедиться, что файл не подменён, можно по контрольной сумме: на странице релиза рядом лежит `.sha256`, а в PowerShell сумму файла покажет `Get-FileHash .\Kordo-Setup-*.exe`.

Если при установке появится сообщение про **WebView2** — согласитесь его скачать и запустите скачанный файл. Это компонент Microsoft, которым Kordo рисует окно; в Windows 11 он уже есть.

## Первые шаги

1. **Добавьте сервер.** «Серверы» → «Добавить сервер» → вставьте ссылку (`vless://…`, `ss://…`, `wireguard://…`) или содержимое `.conf`-файла WireGuard. Можно заполнить и вручную.
2. **Выберите приложения.** «Приложения» → «+ Добавить» → отметьте нужные → выберите сервер в поле «Маршрут» → «Добавить».
3. **Подключитесь.** На экране «Подключение» нажмите большую кнопку. Когда загорится «Подключено», выбранные приложения пойдут через свои серверы.

Маршрут приложения можно поменять в любой момент прямо в списке — соединения при этом не рвутся.

## Настройки простыми словами

| Настройка | Что это |
|---|---|
| **Через VPN идут** | «Выбранные» — только приложения из списка; «Все, кроме выбранных» — весь компьютер через сервер, а приложения из списка идут как указано. |
| **Kill switch** | Что делать, если связь с сервером пропала: «Выкл» — ничего; «VPN-приложения» — им интернет блокируется, остальным нет; «Весь трафик» — блокируется всё, кроме локальной сети. |
| **DNS** | «Через VPN» (рекомендуется) — запросы VPN-приложений идут через сервер, остальных — напрямую, но всё зашифровано. «DoH напрямую» — все запросы зашифрованно напрямую. «Системный» — как без Kordo. |
| **Локальная сеть мимо VPN** | Принтеры, NAS, роутер остаются доступны, даже если приложение идёт через VPN. |
| **Подключаться при запуске Windows** | VPN включится сам после перезагрузки. |
| **Открывать окно при входе** | Kordo запускается в трей при входе в Windows. |
| **Проверять обновления** | Раз в полсуток Kordo смотрит, нет ли новой версии на GitHub. |
| **Дополнительно** | Технические вещи (MTU, стек туннеля, строгая маршрутизация). Меняйте, только если что-то не работает — см. ниже. |

## Если что-то не так

**Пропал интернет.** Скорее всего, сработал kill switch, потому что сервер недоступен. Нажмите «Отключить» или выключите kill switch. Если интернет не вернулся — «Настройки» → «Дополнительно» → «Фильтры брандмауэра: Снять все».

**Приложение идёт не туда.** Откройте «Активность» и посмотрите, через что оно подключено. Многие программы (браузеры, мессенджеры) запускают вспомогательные процессы — Kordo запоминает их автоматически и показывает под приложением в списке; там же им можно поменять маршрут. Если программа запускает «общие» инструменты (cmd, PowerShell, Python, Node), Kordo спросит, куда их направить.

**Медленно или подвисают сайты.** Попробуйте «Дополнительно» → «MTU туннеля» = 1500 (или 1280). Если тормозит всё под нагрузкой — проверьте, что «Стек TUN» стоит `gvisor`.

**Окно не открывается.** Не установлен WebView2 — скачайте его у [Microsoft](https://go.microsoft.com/fwlink/p/?LinkId=2124703). Служба и VPN при этом работают.

**Нужна помощь.** «Журнал» → «Диагностика» сохранит файл с состоянием Kordo. Паролей и ключей серверов в нём нет, но в журналах могут быть адреса сайтов и серверов — просмотрите файл перед отправкой. Приложите его к [issue на GitHub](https://github.com/PeaChack/Kordo/issues).

## Обновление и удаление

**Обновление** — при выходе новой версии внизу слева появится «Доступна версия…» → «Обновить». Или просто поставьте новый установщик поверх: настройки сохранятся.

**Удаление** — «Параметры Windows» → «Приложения» → Kordo → «Удалить». Kordo снимет все свои правила брандмауэра и спросит, удалить ли ваши серверы и настройки (по умолчанию они остаются на случай переустановки).

## Конфиденциальность

- Kordo не собирает статистику и никуда не отправляет данные о вас.
- Серверы и настройки хранятся только на вашем компьютере, в `C:\ProgramData\Kordo`; пароли и ключи серверов зашифрованы средствами Windows (DPAPI).
- Сам Kordo обращается только к GitHub (проверка обновлений, можно выключить), к DNS-серверу DoH (по умолчанию Cloudflare `1.1.1.1`, меняется в настройках DNS) и к `cp.cloudflare.com` / `www.gstatic.com` через ваши серверы — чтобы проверить, что сервер работает.
